🖼️ Card Art Archive

Original issuer card images are stored under images_org/ (and aliased at images/) to guarantee availability and prevent broken links:

# Original path
https://alokc83.github.io/credit-card-bonuses-api/images_org/chase/sapphire-preferred.png

# Upstream-compatible alias
https://alokc83.github.io/credit-card-bonuses-api/images/chase/sapphire-preferred.png

🔄 Synchronization & Automation

  • Daily Sync: GitHub Actions automatically pulls latest changes from upstream andenacitelli/credit-card-bonuses-api daily at 06:00 UTC.
  • Automated Ingestion: Downloads new card art textures from catalog entries directly into images_org/.
  • CORS Enabled: GitHub Pages serves all endpoints with Access-Control-Allow-Origin: *.

Quick Example

curl -s https://alokc83.github.io/credit-card-bonuses-api/exports/data.json | jq '.[0]'
